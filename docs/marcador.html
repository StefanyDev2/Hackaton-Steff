Marcador

Cada equipo corre npm run verificar y sube su progreso.json; aquí se suman los puntos de cada etapa y 3, 2 y 1 más para quienes la completan primero. Se actualiza solo cada 30 segundos.

Equipos que participan

Un repositorio por línea, como usuario/hackaton-equipo-1. Deben ser públicos. GitHub guarda cada archivo hasta 5 minutos.

Todavía no hay equipos

Abre Equipos que participan, pega los repositorios y pulsa Cargar equipos; si un repositorio es privado, recoge su progreso.json y súbelo con Cargar archivos; o ensaya el marcador con Ver con datos de ejemplo.
