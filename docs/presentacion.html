El caso · Notas del semestre

Una API que cuida las notas de un semestre

Quién y qué

Cada estudiante registra sus evaluaciones (nombre, peso y nota) y quiere saber cuánto lleva acumulado.

El problema de hoy

Una hoja de cálculo: los pesos suman 120 %, aparece una nota de 7 y hay nombres repetidos.

Lo que se pide

Una API que cuide las reglas. Hoy la usa una web; mañana, una app y un bot.

Un ejemplo

EvaluaciónPesoNota
Parcial 130 %4.5
Taller20 %3.8
Proyecto50 %—

Acumulado: 2.11, con el 50 % del semestre calificado.

30 % × 4.5 + 20 % × 3.8

Quién pregunta

Web · app · bot

El caso · las reglas

Seis reglas, y quién se entera de cada una

La regla del negocioEl dominio avisa conHTTP responde
El nombre es obligatorio (hasta 40 caracteres)NOMBRE_INVALIDO422
El peso es un entero entre 1 y 100PESO_INVALIDO422
La nota va de 0 a 5NOTA_INVALIDA422
El nombre no se repiteNOMBRE_REPETIDO409
Los pesos juntos no pasan de 100PESO_EXCEDIDO409
La evaluación tiene que existirNO_EXISTE404

Además, un cálculo

Acumulado = suma de peso ÷ 100 × nota. Con 30 % × 4.5 y 20 % × 3.8 da 2.11.

Cada capa, lo suyo

El dominio dice qué regla se rompió. El adaptador HTTP decide cómo contarlo: 422, 409 o 404.

      return repositorio.guardar(nueva);

}

Y la API

La API es un adaptador de entrada: traduce, no decide

Petición HTTP

POST /v1/evaluaciones con un JSON

Adaptador HTTP

Lee el JSON y llama al caso de uso

Caso de uso

Orquesta: pide, decide, guarda

Dominio

Aplica las reglas o lanza un error

Y vuelve: el error del dominio se traduce a un estado HTTP, por ejemplo 422 si la regla no se cumple o 404 si no existe.

En la clase de APIs la regla era «las rutas traducen, no deciden». Esto es lo mismo con otro nombre.

npm run verificar corre las comprobaciones de cada etapa.

Se anota

Queda en progreso.json, con la hora. git push lo envía al marcador.

Se suma

Puntos de la etapa, más 3, 2 o 1 por llegar primero, segundo o tercero.

Juego limpio: el docente puede repetir el verificador en cualquier repositorio, y un resultado que no se reproduce no cuenta.
